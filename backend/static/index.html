Zero payment credentials exposed or called during rejection

                        
When the Policy Gate encounters a failure (signature verification mismatch, category block, trust level threshold breach, or budget overspend), execution halts immediately in local SQLite memory. The backend strictly skips the Razorpay API execution call (returns razorpay_url: null), rendering injection or DB manipulation attacks completely powerless.
